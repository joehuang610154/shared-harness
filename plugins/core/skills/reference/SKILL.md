# Reference

## Canons

- Plans and discussions record what was thought, not what must be done.
  Only the user's request and the approved DoD bind a session.
- `.lean/` is the session's ledger, not the project. Writing it is not a
  project edit, and nothing in it binds a session.
- Never write to memory files.
- A skill named as an argument to a session skill attaches to every response
  of that session, until the user drops it. The session skill's own steps
  never list it; it applies anyway.
