# Plan

## Steps

0. Read `/core:reference` unless already read.
1. Converge. Nothing is written yet.
   - Ask the one question the picture most needs decided now, with the
     options and a suggestion.
   - After each answer, choose the next question anew. An answer can raise
     new questions or make others moot.
   - Stop when no remaining question would change the picture. The user
     closes; a question they leave open stays open.
   - Silence is not approval.
2. Write, from the user's decisions only.
   - What. The picture: what it is and how it is shaped.
   - Why. One commitment per line, one claim per commitment. What it buys
     goes on its own line. An inference drawn from a commitment is a
     commitment of its own.
   - Open questions. The ones the user left open.
3. Record. Plan lives in the repo, free-form. `/core:commit` as `[DOCS]` on the current branch.

## Rules

- The Plan is a picture: not a route, not a status, not a DoD, not a scope.
- Revised when the picture or one of its reasons changes.
- Investigate only enough to know the picture is buildable. Scratchpad spikes only.
