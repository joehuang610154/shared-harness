# Discussion

0. Read `/core:reference` unless already read.
1. Name the topic. One sentence.
2. Talk. Read what the topic needs. Scratchpad only.
3. Record, if the user asks. Free-form, in the repo. `/core:commit` as `[DOCS]` on `develop`.

## Rules

- No project edits.
- The user closes. Nothing is owed at close: no answer, no statement, no summary.
