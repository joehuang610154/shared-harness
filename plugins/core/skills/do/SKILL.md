# Do

## Steps

0. Read `/core:reference` unless already read.
1. Read the request. Say what it is missing, in one sentence.
2. Name the route by what is missing.
3. Say the route and its reason in one line, then run that skill.
   Two routes fitting is the user's call: ask, then run.

## Routes

| Missing                             | Route      |
|-------------------------------------|------------|
| An answer                           | Discussion |
| A shape, or too big for one session | Plan       |
| Only the work                       | Task       |

## Rules

- One route, one session. A Plan does not roll on into its Task.
- `do` decides nothing else. Every rule of the routed skill stands, its
  approval gates included.
